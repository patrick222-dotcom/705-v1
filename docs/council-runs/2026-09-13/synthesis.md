# Council 2026-09-13 — synthesis (authoritative statuses: 85 confirmed, 14 rejected, 0 unverified, 34 low never verified)

**Verdict.** The math core held: no confirmed finding shows `shiftGross`/`computeNet` computing a wrong figure for any input the UI can produce, and six of seven data-integrity findings (all the sync-race ones) were rejected, so the whole-blob sync design stands. What did not hold: (a) the *surfaces around* the math — Add-Shift preview, hero chip, pattern lab, onboarding — disagree with `computeNet` or present a fake/averaged figure as certain; (b) the swap board's anonymity promise is false as deployed (one critical, live-verified on the production project); (c) three claims in CLAUDE.md/docs are wrong; (d) a large but cheap a11y + tap-target cleanup. No app code has shipped since the run (only council-doc commits) and I re-checked every load-bearing line cited below against the current `index.html`; they all hold. Every lens is below 8; two of them (security, accessibility) genuinely so, the rest converge on one wage-core session plus nightly-sized work.

**Confirmed, but with a dissenting refuter you should know about** (majority still confirmed): `cross-surface-00` (there is no custom-withholdings editor — only reachable via Export→hand-edit→Import), `wage-math-10` (the "fixed cells keep their type" contract is documented in the code comment; the defect is the hint copy), `wage-math-06` (single-stub parser; the negative amount is visible on the review sheet, not silent), `security-02`/`-03` (need a hostile co-member hand-crafting REST calls), `data-integrity-00` (the debounce timer is *not* cancelled on background, so loss needs: edit in the last 500ms + failed write + OS kills the suspended tab), `code-quality-03` (the customWithholdings repro is unreachable because Import JSON flips `setupComplete`), `code-quality-11` (only bites a user who signed up without ever using the app anonymously), `mobile-ux-02` and `accessibility-09` (page just scrolls / cells are focusable — nits), `accessibility-15`'s focus half and `cross-surface-02` (restate a documented tradeoff/design choice).

**Money surfaces**

1. **Add-Shift sheet defaults to `'night'` even when Night is switched off, and prices it** — `wage-math-12` = `cross-surface-01`; same root cause as lows `wage-math-03/-07`, `cross-surface-06` (`hourlyRate` at 1119-1124 never reads `active`). `useState('night')` at 4077 is never reconciled with the `active`-filtered chips at 4099, so no chip is lit yet the preview and the saved shift carry the Night differential (+$120/shift at $50 base); the pattern lab prices the same setup at base. Fix: seed from the first active non-overtime key + a small effect if the current type leaves `active`. Underneath it a **product call**: does `active:false` mean "stop paying" (lab) or "hide from the picker" (calendar/`calc`/`statOf`)? Both surfaces currently answer differently. **B3** (cheapest item there).
2. **Hero "Taxes & deductions" chip is uncapped** — `product-design-00` (high) = `wage-math-00` = `cross-surface-03` (low). 3487 prints raw `calc.ded`; `computeNet` caps `pre`/`post` for the Breakdown (1246-1249) and never caps flat-dollar custom withholdings. **Swap board and security (production project, live-verified)**

15. **`poster_key` is reversible** — `security-00` (critical). `authenticated` holds SELECT on `swap_members(user_id)` and `swap_groups(created_by)` (001:59-69), the salt is a public constant (001:158, repo is public), md5 is a one-liner: one REST select + one loop maps every poster_key to a uuid for the whole board; the creator is named outright. The 07-30 audit checked only that `author` can't be selected. This is *not* the KNOWN stable-key item (recognisability after a match) — it is reversibility before any match. Fix step 1 (grants only): revoke SELECT/UPDATE on `swap_members` and `swap_groups` from `authenticated`, re-grant `select (id,name,invite_code,created_at)` on groups (client never selects those columns — 1675/1706/1719 checked). Step 2: per-group random secret in a no-grant table, read inside `swap_board()`. Then rewrite Invariant 7, `docs/swap-board.md`, the migration comment ("Not reversible") and the in-app "anonymously" copy. **B2**.
16. **`propose_swap` never checks the caller is a leg** — `security-01` (high). Any member can pair any two open posts (001:245-265); both flip to `proposed` and vanish from the board, the proposer can't be seen or declined, and re-proposes every 15s. Fix: `raise 'not_a_party'` unless a leg's `leg_user = auth.uid()`; optional cap on concurrent proposals. **B2**.
17. **Raw "parties decline matches" UPDATE policy bypasses `decline_swap_match`** — `security-02`. A direct PATCH to `status='declined'` never releases the posts; the other party's post is stuck `proposed` (001:130, 277-278). Fix: drop the policy, revoke `update` on `swap_matches`. **B2** (same migration as 15/16).
18. **"Add to my calendar" writes another member's unvalidated `shift_meta` into her shifts** — `security-03`. 5285 pushes `meta.hours` uncoerced → hero "$NaN" until reload, then `sanitizeData` drops the shift she just picked up. Client guard (object, string `shiftType`, finite hours in (0,24], `start` matches `TIME_RE`) is **B1**; the `jsonb_typeof`-guarded CHECK on `swap_posts.shift_meta` joins the **B2** migration.
19. **`MAX_BLOB_BYTES` exists only in the browser; `user_data.data` has no server-side bound** — `security-05` (high) ⊃ `code-quality-19`. No CHECK/trigger live (pg_constraint verified); `flush()` (2496) and `retrySync()` (2512) — the exact "retry" button shown after the oversize toast — call `saveToSupabase` with no size check; the check compares UTF-16 units to a byte budget. Fix: migration 004 `check (pg_column_size(data) <= 524288)` + `jsonb_typeof = 'object'` (**B2**, same session); move the check into `saveToSupabase` using `TextEncoder` so all three call sites share it, and treat 23514 as a failed save (**B1**).
20. **`ical-proxy` accepts the public anon key** — `security-08`. Live probe: `Bearer <anon key from 616>` runs the handler (422, not 401); `www.google.com` is allowlisted with no path constraint and CORS `*`, so it is an anonymous relay against free-tier egress. Fix: require `role === 'authenticated'` + uuid `sub`, pin the Google entries to `/calendar/ical/`, redeploy, add the negative curl to the ship ritual, correct index.ts:8-9 and CLAUDE.md. **B2**.
21. **Google sign-in runs the implicit flow, not PKCE** — `security-11` (+ `code-quality-25`). `createClient(url,key)` at 610-615 takes supabase-js 2.45.4's default `flowType:'implicit'`; tokens land in `#access_token=…&refresh_token=…`, and the post-load `hash=''` leaves that URL one Back-press away (verified in the sandbox). Fix: `{auth:{flowType:'pkce'}}` — one line, but verify with a never-signed-in Google account on a real phone (the redirect allow-list is unchanged; `takeSwapInviteFromUrl` preserves `?code=`). PKCE adds a `localStorage.setItem` inside `signInWithOAuth` that throws in Safari private mode, which is when `code-quality-25`'s missing try/catch/finally (4615-4628) becomes real — do both together. **B2**.
22. **`client_error` batches over ~1,700 chars are rejected by the live `events_props_check` after the ring buffer was already cleared** — `security-12`. Measured: 6×300-char entries = 2,348 jsonb bytes > 2,000. The session that most needs diagnosing is the one that reports nothing. Fix: cut `msg` to ~160 chars and drop oldest while `JSON.stringify(props).length > 1700`; harness assertion seeding 8 long entries. **B1**.
